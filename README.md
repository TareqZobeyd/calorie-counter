🥗 Calorie Counter

A simple calorie tracking web application that allows users to select a food item and its portion size, then automatically retrieves nutritional information — such as calories, protein, fat, and carbohydrates — using the OpenAI API.

🚀 Features

Select food and portion size

Send requests to OpenAI API using an API key

Receive and display calorie and nutrition data

Fast and lightweight backend integration

Built with clean and secure environment variable configuration

🧠 How It Works

The user selects a food and its amount.

The app sends the data to ChatGPT (OpenAI API) using the provided API key.

The API responds with detailed nutritional information.

The app displays the results in a simple and clear interface
